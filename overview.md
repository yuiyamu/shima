# shima package manager

should have a cli.c that the user actually uses in order to interact with our packages, download, etc

we should make a directory called `/etc/shima` where we store our stuff, and 
`/etc/shima/shima.repos` should be what we read to find packages to download ^-^

## package creation

packages should be created with a `campsite` file, defined like this

### campsite
campsite-ver: 0.1 (needs to be at the top)
name: fish
desc: the friendly, interactive shell
pkgver: 4.0.1-shm0

= sources =
./fish.zip <- should always be a zip so we can natively extract it :3
i would like to add patches at some point, but that can wait!!
also maybe md5sum at some point, but can also wait.

= depends =
rust-1.0.67-shm0
cargo-4.3-shm1

= prepare = (used for the actual build commands we need :p)
./configure prefix=${pwd}
make -j$(nproc)
make install

= post-install =
# commands to be run after installation on the system!! can be symlinking whatever or whatever yeah.

### package building

once a campsite is defined, `shima build [campsite]` can be invoked to build it into `fish-4.0.1-shm0.shm` which is just a zip file Lol

## package installation

packages should be installed with `shima install [package]`, but even in the base version id like it to support both ./package and "fish" and itll go search and see if it can find fish anywhere
